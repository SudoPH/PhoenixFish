# Security Policy

## Supported Versions

Security updates are currently provided for the latest stable release of PhoenixFish.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

If you discover a security vulnerability in PhoenixFish, please do not create a public GitHub Issue.

Please report security vulnerabilities privately through GitHub Security Advisories or contact the project maintainer directly.

When reporting a vulnerability, please include:

- A description of the vulnerability
- Steps to reproduce the issue
- Affected PhoenixFish version
- Minecraft and server software version
- Relevant logs or screenshots
- Potential impact of the vulnerability

Please allow reasonable time for the issue to be investigated and fixed before publicly disclosing the vulnerability.

## Security Updates

Confirmed security vulnerabilities will be addressed in a future release when possible.

Security fixes may be included in patch releases such as `v1.0.1`, `v1.0.2`, etc.
